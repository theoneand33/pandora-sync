Pandora P2P Sync

Hosts the share page and the relay on one origin. Deploy this repo once on Deno Deploy, Netlify, Cloudflare, or Google Cloud Run — no separate service needed. The launcher uploads a filtered zip, this page fetches it.

Receive

Paste the token or the share link from the launcher. A full link like <this-origin>/p2p/<token>, or a bare token with ?token=<token>.

How it works

  • One deployment: the page and the relay are the same origin on Deno Deploy, Netlify, Cloudflare, or Google Cloud Run. The launcher PUTs to /p2p/<token>, this page GETs it back.
  • Ephemeral: the token is the only auth. Bundles expire after 30 minutes and live in the deployment's memory, so a fresh cold start can lose one.
  • The launcher bundle is a zip filtered by ExportOptions (mods/config/etc). Receiver validates every path via SafePath.
