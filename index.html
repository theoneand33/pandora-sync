Pandora P2P Sync

Separate website for syncing instances. Works with GitHub Pages (static) and a Coolify relay. The launcher uploads a filtered zip, this page fetches it.

Receive

Paste the link from the launcher. Works with https://relay.example.com/p2p/<token> or ?token=<token>.

How it works

  • GitHub Pages: hosts this static page only. Storage lives on the Coolify relay. No binary touches GitHub.
  • Coolify: run the relay at RELAY_URL (PUT /p2p/<token> stores, GET /p2p/<token> returns, 30 min TTL). See site/README.md.
  • The launcher bundle is a zip filtered by ExportOptions (mods/config/etc). Receiver validates every path via SafePath.
